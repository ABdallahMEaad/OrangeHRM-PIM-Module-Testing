# OrangeHRM PIM Module Testing

## Project Overview
This repository contains a complete Manual Testing project for the OrangeHRM PIM (Personnel Information Management) Module.

The project demonstrates end-to-end QA activities including:

- Test Planning
- Test Case Design & Execution
- Defect Reporting
- Requirement Traceability Matrix (RTM)
- Test Execution Tracking
- QA Metrics & Reporting

## Test Deliverables

### Test Plan
Contains:
- Scope
- Objectives
- Entry Criteria
- Exit Criteria
- Risks
- Assumptions
- Environment Details

### Test Cases
Includes:
- Test Case ID
- Module
- Preconditions
- Test Data
- Test Steps
- Expected Results
- Priority
- Status

### Test Execution
Execution results for all designed test cases.

### Bug Reports
Defects identified during testing with:
- Severity
- Priority
- Status
- Reproduction Steps
- Expected vs Actual Results

### RTM (Requirement Traceability Matrix)
Maps business requirements to corresponding test cases.

### Execution Summary
Provides:
- Total Test Cases
- Passed Test Cases
- Failed Test Cases
- Pass Rate
- Defect Count

## Severity Levels

### Critical
Application functionality is completely blocked or security is compromised.

### High
Major business functionality is affected.

### Medium
Partial functionality issue with available workaround.

### Low
UI, cosmetic, or minor usability issue.

---

## Priority Levels

| Priority | Description |
|----------|-------------|
| P1 | Must be fixed immediately |
| P2 | High business importance |
| P3 | Can be fixed in future release |
